2. รายละเอียดโครงสร้างตารางผู้ใช้งาน (Table: `users`)

ตารางหลักสำหรับจัดเก็บข้อมูลผู้ใช้งานในระบบ เพื่อรองรับฟังก์ชัน Login, Dashboard, จัดการผู้ใช้ (CRUD) และแก้ไขโปรไฟล์

Column Name Data Type Constraints & Keys Default คำอธิบาย (Description)
id BIGINT / INTEGER PRIMARY KEY AUTO_INCREMENT - รหัสประจำตัวผู้ใช้งาน (Primary Key)
name VARCHAR(255) NOT NULL - ชื่อ-นามสกุลของผู้ใช้งาน
email VARCHAR(255) UNIQUE INDEX NOT NULL - อีเมลสำหรับใช้เข้าสู่ระบบ (ห้ามซ้ำ)
email_verified_at DATETIME / TIMESTAMP NULLABLE NULL วันเวลาที่ทำการยืนยันอีเมล
password VARCHAR(255) NOT NULL - รหัสผ่านที่เข้ารหัสทางเดียวด้วย Bcrypt Hashed
remember_token VARCHAR(100) NULLABLE NULL Token สุ่มสำหรับระบบ "จดจำการเข้าสู่ระบบ"
created_at DATETIME / TIMESTAMP NULLABLE CURRENT_TIMESTAMP วันเวลาที่สร้างรายการผู้ใช้
updated_at DATETIME / TIMESTAMP NULLABLE CURRENT_TIMESTAMP วันเวลาที่แก้ไขข้อมูลล่าสุด
🔒 ความปลอดภัยของรหัสผ่าน: ทุกรหัสผ่านในระบบถูก Hash ด้วยอัลกอริทึม Bcrypt ผ่าน Hash::make() และ Eloquent Casts 'password' => 'hashed' ทำให้ไม่มีการจัดเก็บ Plain Text ในฐานข้อมูลเด็ดขาด

3. ตารางสำหรับระบบความปลอดภัยและเซสชัน (Supporting Tables)

3.1 ตาราง `sessions` (Session Management)

Column Name Data Type Key / Index คำอธิบาย (Description)
id VARCHAR(255) PRIMARY KEY Session Token ID เฉพาะของแต่ละการเชื่อมต่อ
user_id BIGINT / INTEGER INDEX (FOREIGN KEY) รหัสของผู้ใช้ที่ล็อกอินอยู่ (เชื่อมโยงกับ users.id)
ip_address VARCHAR(45) NULLABLE หมายเลข IP Address ของผู้ใช้งาน
user_agent TEXT NULLABLE ข้อมูล Browser และระบบปฏิบัติการของผู้ใช้งาน
payload LONGTEXT NOT NULL ข้อมูล Serialized Session Payload (เข้ารหัส)
last_activity INTEGER INDEX Unix Timestamp ของการใช้งานล่าสุด สำหรับหมดอายุ Session

3.2 ตาราง `password_reset_tokens` (Password Recovery)

Column Name Data Type Key คำอธิบาย
email VARCHAR(255) PRIMARY KEY อีเมลผู้ใช้งานที่ร้องขอการรีเซ็ตรหัสผ่าน
token VARCHAR(255) NOT NULL Token เข้ารหัสสำหรับยืนยันสิทธิ์การรีเซ็ตรหัสผ่าน
created_at DATETIME NULLABLE วันเวลาที่สร้าง Token สำหรับกำหนดเวลาหมดอายุ

5. คำสั่ง DDL สรุป (Standard MySQL Schema)

CREATE TABLE `users` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255) NOT NULL,
  `email` VARCHAR(255) NOT NULL UNIQUE,
  `email_verified_at` TIMESTAMP NULL DEFAULT NULL,
  `password` VARCHAR(255) NOT NULL,
  `remember_token` VARCHAR(100) DEFAULT NULL,
  `created_at` TIMESTAMP NULL DEFAULT NULL,
  `updated_at` TIMESTAMP NULL DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
